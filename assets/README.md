# Photos & illustrations

Drop your images in this folder.

## Save-the-date illustration (hero)
Save your watercolour save-the-date image here as:

```
assets/save-the-date.png
```

It will automatically appear as the centerpiece of the hero section, and the
typeset names will step aside for it. JPG works too — just rename the file to
`save-the-date.png`, or update the `src` in `index.html` (search for `heroCard`).

If the file isn't present, the site falls back to the elegant typeset hero — so
nothing breaks either way.

## Gallery photos
Add your engagement / couple photos here and update the `src` values in the
Gallery section of `index.html` (they currently use placeholder images).
